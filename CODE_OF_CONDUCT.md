# Code of Conduct

This project adheres to the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating, you agree to:

- Use welcoming and inclusive language
- Be respectful of differing viewpoints and experiences
- Accept constructive criticism gracefully
- Focus on what is best for the project and community

Unacceptable behavior includes harassment, personal attacks, or abusive language. Project maintainers will enforce this code; violations may result in removal from issues, PRs, or the project entirely.

Report concerns to the maintainers listed in `package.json`.
